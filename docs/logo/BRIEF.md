# Brief logo : Request

- **Nom** : Request (graphie exacte, un seul mot, U et R capitales).
- **Ce que c'est** : les membres d'un serveur Emby privé demandent des films et des séries ; le propriétaire approuve ; le titre se télécharge ; « c'est dans Emby ».
- **Public** : une poignée de proches, sur ordinateur et téléphone, pas des techniciens.
- **Personnalité** : cinématographique, calme, haut de gamme, chaleureux, pas technique.
- **Doit fonctionner** : sur fond `#07080A` (principal) et sur le thème clair `#F2F2F5` ; en favicon 16 px ; à gauche du header, à côté de la pilule de verre ; en icône d'écran d'accueil (180 et 512 px).
- **Couleurs** : uniquement les tokens : blanc `#F5F5F7` (`--text`), beige `#E8C9A6` (`--accent-play`, `#B07A45` en thème clair), quasi-noir. Une version monochrome doit tenir seule.
- **Typographie** : Inter Variable (déjà dans l'appli), graisse 600, approche -2 %, vectorisée dans les lockups (pas de texte vivant).
- **Pistes** : la demande (plus, main, billet), le cinéma (billet, pellicule, lecture), l'arrivée (validé, flèche), l'initiale U.
- **Clichés à éviter** : dégradés violets, emoji, bouton lecture « plateforme vidéo », flèche de téléchargement générique, look « IA ».
- **Hypothèses** : pas de logo existant à préserver ; le symbole seul sert de favicon et d'icône ; décision par le propriétaire.
